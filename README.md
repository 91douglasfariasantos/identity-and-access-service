## 🛡️ Identity and Access Core

O Identity and Access Core é um projeto de autenticação focado na criação de interfaces modernas e funcionais. Desenvolvido no contexto de mentorias técnicas, o projeto simula um ambiente real de desenvolvimento Front-End, aplicando boas práticas de usabilidade e responsividade.

## 🚀 Tecnologias
O projeto foi construído utilizando uma stack essencial para o mercado de Front-End:

- Markup & Styling: HTML5, CSS3, Bootstrap 5.

- Lógica: JavaScript (ES6+).

- Arquitetura: Organização modular de ativos.

## 🛠️ Funcionalidades Implementadas

- Autenticação: Telas de Login e Cadastro com validação de campos.

- Design Responsivo: Layout fluido que se adapta desde dispositivos móveis até grandes monitores.

- Componentização: Uso eficiente de componentes do Bootstrap para manter a consistência visual.

- Experiência do Utilizador (UX): Interface intuitiva focada em facilidade de acesso.

## 📥 Como clonar o projeto

Para ter acesso ao código e executar o projeto localmente, siga os passos abaixo:

- Pré-requisito: Tenha o Git instalado na sua máquina.

- Clonar o repositório: Abra o terminal no diretório desejado e execute o comando:

```bash
# Clone o repositório
git clone https://github.com/91douglasfariasantos/identity-and-access-service 

# Acesse a pasta do projeto
cd identify-and-access-service

```

## Rodar projeto 

- Abra o index.html diretamente no seu navegador de preferência.
